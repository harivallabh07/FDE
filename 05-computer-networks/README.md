# 05 — Computer Networks

**Goal:** Understand how an application communicates across a network and debug common failures.

## Topics
- OSI and TCP/IP models; encapsulation
- IP addressing, subnet basics, routing, ports
- TCP versus UDP, handshakes, retransmission
- DNS resolution
- HTTP methods, headers, status codes, cookies
- HTTPS, TLS, certificates
- Sockets, proxies, load balancers, CORS
- Latency, throughput, packet loss

## Practical assignments
- Inspect DNS and HTTP requests with command-line tools.
- Build a simple client/server socket exercise.
- Trace a browser-to-API request and document the path.

**Definition of done:** diagnose common DNS, connection, TLS, and HTTP errors.
