# 01 — Data Structures and Algorithms

**Goal:** Select appropriate data structures and reason about time and space complexity.

## Topics
- Big-O, time/space complexity, trade-offs
- Arrays, strings, hash maps, sets
- Two pointers, sliding window, prefix sums
- Linked lists, stacks, queues, deques
- Recursion, backtracking, sorting, binary search
- Trees, BSTs, heaps, tries
- Graphs: BFS, DFS, shortest paths, topological sorting
- Dynamic programming fundamentals

## Hands-on assignments
1. Implement linked list, stack, queue, hash map (simplified), tree traversal, and graph traversal in Python.
2. Solve at least 30 problems grouped by pattern; explain the approach before coding.
3. For every solution, record complexity, edge cases, tests, and a short reflection.

**Definition of done:** implement core structures independently and explain the complexity of your solutions.
