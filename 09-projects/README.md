# 09 — Portfolio Projects

**Goal:** Demonstrate end-to-end engineering ability through useful, deployed projects.

## Suggested progression
1. **DSA implementation set:** tested implementations and problem explanations.
2. **OOP + networking utility:** modular socket-based client/server tool with protocol notes.
3. **Backend service:** FastAPI + persistence + authentication + tests.
4. **ML application:** reproducible training, evaluation, and inference API.
5. **RAG application:** document ingestion, retrieval, grounded answers, evaluation.
6. **Capstone FDE project:** solve a defined user/business workflow with AI, deployment, observability, and a polished demo.

## Required project documentation
- Problem and target user
- Requirements and non-goals
- Architecture diagram and data flow
- Setup instructions and environment-variable example
- API usage or user guide
- Tests and evaluation results
- Failure modes, security/privacy considerations, cost and latency trade-offs
- Deployment link, screenshots, and demo

Prefer a few complete, well-explained projects over many unfinished prototypes.
