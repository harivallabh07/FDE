# 03 — Object-Oriented Programming

**Goal:** Design maintainable applications using sound object-oriented principles.

## Topics
- Classes, objects, attributes, methods, constructors
- Encapsulation, abstraction, inheritance, polymorphism
- Composition versus inheritance
- Interfaces/protocols, abstract base classes, dependency injection
- SOLID principles and common design patterns
- UML/class diagrams and refactoring

## Practical assignments
1. Model a small inventory or booking domain.
2. Separate domain logic, persistence, and presentation.
3. Refactor tightly coupled code using composition and dependency injection.

**Definition of done:** justify class boundaries and demonstrate testable, loosely coupled components.
