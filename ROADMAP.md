# Six-Month AI-Focused FDE Roadmap

This is a sequence, not a rigid deadline. Complete the practical outcomes before moving on. A reasonable weekly cycle is concept study, implementation, review, and a visible GitHub deliverable.

## Phase 1 — Software engineering foundations (Weeks 1–4)

- **Week 1 — Python and tooling:** syntax review, functions, modules, exceptions, virtual environments, Git/GitHub, debugging. Deliverable: small command-line utility with tests.
- **Week 2 — Problem solving and DSA I:** complexity, arrays, strings, hashing, two pointers, stacks, queues. Deliverable: documented problem set.
- **Week 3 — DSA II:** linked lists, trees, heaps, graphs, recursion, sorting, searching. Deliverable: implementations and complexity notes.
- **Week 4 — OOP and clean design:** classes, objects, encapsulation, inheritance, polymorphism, abstraction, composition, SOLID basics. Deliverable: a modular Python application.

## Phase 2 — Core computer science (Weeks 5–8)

- **Week 5 — Operating systems I:** processes, threads, scheduling, context switching, system calls.
- **Week 6 — Operating systems II:** virtual memory, paging, filesystems, synchronization, deadlocks, concurrency.
- **Week 7 — Computer networks:** OSI/TCP-IP, IP, TCP/UDP, DNS, HTTP/HTTPS, TLS, sockets, ports.
- **Week 8 — DBMS:** relational modelling, SQL, joins, indexes, transactions, ACID, isolation, normalization. Deliverable: database-backed application.

## Phase 3 — Backend engineering (Weeks 9–12)

- **Week 9:** REST principles, HTTP methods/status codes, JSON, API design.
- **Week 10:** FastAPI, validation, dependency injection, error handling, API documentation.
- **Week 11:** authentication/authorization, configuration, logging, testing, database integration.
- **Week 12:** async basics, caching, background jobs, reliability, API deployment. Deliverable: tested backend service.

## Phase 4 — Machine learning and deep learning (Weeks 13–16)

- **Week 13:** supervised learning, regression, classification, data leakage, preprocessing.
- **Week 14:** trees, ensembles, feature engineering, metrics, cross-validation, error analysis.
- **Week 15:** neural-network fundamentals, tensors, autograd, training loops, PyTorch.
- **Week 16:** optimization, regularization, transfer learning, GPU basics, experiment tracking. Deliverable: reproducible ML/DL project.

## Phase 5 — LLM engineering (Weeks 17–20)

- **Week 17:** tokenization, embeddings, transformers, inference, Hugging Face pipelines.
- **Week 18:** vector search, chunking, retrieval, reranking, RAG architecture.
- **Week 19:** prompt design, tool/function calling, structured outputs, agent workflows, safety.
- **Week 20:** LLM evaluation, tracing, latency/cost trade-offs, hallucination analysis. Deliverable: evaluated RAG application.

## Phase 6 — Deployment and FDE portfolio (Weeks 21–24)

- **Week 21:** Linux and shell workflows, Docker, containers, environment management.
- **Week 22:** CI/CD, cloud deployment, secrets management, networking in deployment.
- **Week 23:** observability, logs, metrics, tracing, incident debugging, performance.
- **Week 24:** polish and deploy a capstone; write architecture and customer-facing documentation; record a demo; prepare case studies and interview explanations.

## Capstone expectations

Build an end-to-end AI application that solves a concrete user or business problem. It should have a usable interface or API, persistent data where needed, an AI component, evaluation, tests, deployment, observability, and clear documentation. Explain design decisions, failure modes, costs, latency, privacy, and limitations.
