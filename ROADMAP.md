# Six-Month AI-Focused FDE Roadmap

This is a sequence, not a rigid deadline. Complete the practical outcomes before moving on. A reasonable weekly cycle is concept study, implementation, review, and a visible GitHub deliverable.

## Phase 1 — Software engineering and computer science foundations (Weeks 1–6)

- **Week 1 — DSA I:** complexity, arrays, strings, hashing, two pointers, stacks, queues. Deliverable: documented problem set.
- **Week 2 — DSA II:** linked lists, trees, heaps, graphs, recursion, sorting, searching. Deliverable: implementations and complexity notes.
- **Week 3 — OOP:** classes, objects, encapsulation, inheritance, polymorphism, abstraction, composition, SOLID basics. Deliverable: a modular Python application.
- **Week 4 — Computer networks:** OSI/TCP-IP, IP, TCP/UDP, DNS, HTTP/HTTPS, TLS, sockets, ports. Deliverable: a documented client/server networking exercise.
- **Week 5 — Operating systems I:** processes, threads, scheduling, context switching, system calls.
- **Week 6 — Operating systems II:** virtual memory, paging, filesystems, synchronization, deadlocks, concurrency. Deliverable: a small process/thread experiment with debugging notes.

## Phase 2 — Backend engineering (Weeks 7–10)

- **Week 7:** REST principles, HTTP methods/status codes, JSON, API design.
- **Week 8:** FastAPI, validation, dependency injection, error handling, API documentation.
- **Week 9:** authentication/authorization, configuration, logging, testing, persistence integration.
- **Week 10:** async basics, caching, background jobs, reliability, API deployment. Deliverable: tested backend service.

## Phase 3 — Machine learning and deep learning (Weeks 11–14)

- **Week 11:** supervised learning, regression, classification, data leakage, preprocessing.
- **Week 12:** trees, ensembles, feature engineering, metrics, cross-validation, error analysis.
- **Week 13:** neural-network fundamentals, tensors, autograd, training loops, PyTorch.
- **Week 14:** optimization, regularization, transfer learning, GPU basics, experiment tracking. Deliverable: reproducible ML/DL project.

## Phase 4 — LLM engineering (Weeks 15–18)

- **Week 15:** tokenization, embeddings, transformers, inference, Hugging Face pipelines.
- **Week 16:** vector search, chunking, retrieval, reranking, RAG architecture.
- **Week 17:** prompt design, tool/function calling, structured outputs, agent workflows, safety.
- **Week 18:** LLM evaluation, tracing, latency/cost trade-offs, hallucination analysis. Deliverable: evaluated RAG application.

## Phase 5 — Deployment and FDE portfolio (Weeks 19–24)

- **Week 19:** Linux and shell workflows, Docker, containers, environment management.
- **Week 20:** CI/CD, cloud deployment, secrets management, networking in deployment.
- **Week 21:** observability, logs, metrics, tracing, incident debugging, performance.
- **Weeks 22–23:** build and integrate the capstone; test, deploy, and evaluate it.
- **Week 24:** polish the capstone; write architecture and customer-facing documentation; record a demo; prepare case studies and interview explanations.

## Capstone expectations

Build an end-to-end AI application that solves a concrete user or business problem. It should have a usable interface or API, persistent data where needed, an AI component, evaluation, tests, deployment, observability, and clear documentation. Explain design decisions, failure modes, costs, latency, privacy, and limitations.
