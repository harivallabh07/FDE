# 06 — Database Management Systems

**Goal:** Design and query reliable relational databases.

## Topics
- Tables, keys, constraints, relationships, ER modelling
- SQL: SELECT, filtering, joins, aggregation, subqueries
- Normalization and schema design
- Indexes and query plans
- Transactions, ACID, isolation levels, locking
- Migrations, connection pooling, backups
- Introductory NoSQL concepts and trade-offs

## Practical assignments
- Design a normalized schema for a real application.
- Write analytical and transactional SQL queries.
- Connect a FastAPI service to PostgreSQL or SQLite and test persistence.

**Definition of done:** explain schema decisions, indexes, and transaction behavior.
