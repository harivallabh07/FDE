# 01 — Programming Fundamentals

**Goal:** Write readable, testable Python and use a professional development workflow.

## Topics
- Python data types, control flow, functions, scope, comprehensions
- Modules, packages, imports, virtual environments, dependency management
- Exceptions, file I/O, JSON, CSV, pathlib
- Iterators, generators, decorators, context managers
- Type hints, clean code, debugging, logging
- Git, branches, commits, pull requests, GitHub workflow
- Unit testing with pytest

## Practical assignments
1. Build a command-line task tracker that persists data to JSON.
2. Refactor it into modules with type hints and clear error handling.
3. Add unit tests and a useful README.

**Definition of done:** another person can install, run, test, and understand the project.
