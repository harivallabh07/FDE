# 11 — DevOps and Deployment

**Goal:** Ship and operate applications reliably.

## Topics
- Linux shell, processes, permissions, environment variables
- Docker images, containers, volumes, networks
- Configuration and secrets management
- CI workflows, automated tests, build pipelines
- Cloud deployment fundamentals
- Logs, metrics, traces, health checks
- Monitoring, debugging, rollback, reliability
- Security basics and dependency hygiene

## Practical assignments
- Containerize a backend application.
- Add CI to run linting and tests on pushes/pull requests.
- Deploy a project and document configuration, monitoring, and rollback.

**Definition of done:** another person can deploy the application using documented steps without access to your secrets.
