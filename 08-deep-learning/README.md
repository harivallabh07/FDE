# 08 — Deep Learning

**Goal:** Understand neural-network training and implement models with PyTorch.

## Topics
- Tensors, tensor operations, datasets, dataloaders
- Neurons, layers, activations, loss functions
- Backpropagation, autograd, optimizers
- Training/validation loops and regularization
- CNN and sequence-model fundamentals
- Transfer learning and pretrained models
- GPU concepts, CUDA availability, memory constraints

## Practical assignments
- Implement a small training loop.
- Fine-tune a pretrained model on a modest dataset.
- Track experiments and compare CPU versus available GPU execution.

**Definition of done:** explain the training loop, overfitting, metrics, and compute trade-offs.
