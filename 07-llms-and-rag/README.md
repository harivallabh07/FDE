# 07 — LLMs, RAG, and AI Applications

**Goal:** Build useful LLM-powered systems and evaluate them beyond a successful demo.

## Topics
- Tokenization, embeddings, transformers, inference
- Hugging Face models and pipelines
- Prompt design and structured outputs
- Chunking, vector databases, retrieval, reranking
- RAG architecture and citation/grounding strategies
- Tool calling and bounded agent workflows
- Evaluation datasets, retrieval metrics, answer quality
- Hallucinations, prompt injection, privacy, cost, latency

## Free video learning and courses
- [Hugging Face LLM Course — free, official course with video lessons](https://huggingface.co/learn/llm-course/chapter1/1)
- [How Transformer LLMs Work — free DeepLearning.AI course video](https://www.youtube.com/watch?v=k1ILy23t89E)

## Hands-on assignments
1. Use a Hugging Face pipeline for classification or text generation; inspect tokenizer/model outputs.
2. Build a document Q&A RAG prototype with source references.
3. Create a small evaluation set and measure retrieval and answer quality.
4. Add logging, failure handling, prompt-injection tests, and a short system card.

**Definition of done:** demonstrate when the system is reliable, when it fails, and how you measured it.
