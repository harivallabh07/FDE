# 02 — Data Structures and Algorithms

**Goal:** Select appropriate data structures and reason about time and space complexity.

## Topics
- Big-O, time/space complexity, trade-offs
- Arrays, strings, hash maps, sets
- Two pointers, sliding window, prefix sums
- Linked lists, stacks, queues, deques
- Recursion, backtracking, sorting, binary search
- Trees, BSTs, heaps, tries
- Graphs: BFS, DFS, shortest paths, topological sorting
- Dynamic programming fundamentals

## Practical assignments
- Implement core structures in Python.
- Solve and document representative problems by pattern.
- For each solution, record approach, complexity, edge cases, and tests.

**Definition of done:** explain the approach and complexity, then implement it independently.
