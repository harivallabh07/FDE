# 04 — Backend Engineering and APIs

**Goal:** Expose application functionality through robust, documented services.

## Topics
- HTTP and REST API design
- FastAPI, routing, request/response validation
- Pydantic schemas and dependency injection
- Database integration and migrations
- Authentication, authorization, input validation
- Error handling, pagination, rate limiting
- Async I/O, background tasks, caching
- pytest, API integration tests, OpenAPI documentation

## Free video learning
- [Python API Development with FastAPI — freeCodeCamp (full project course)](https://www.youtube.com/watch?v=0sOvCWFmrtA)
- [FastAPI tutorial — Tech with Tim (short practical build)](https://www.youtube.com/results?search_query=Tech+with+Tim+How+to+Create+a+Python+API+with+FastAPI)

## Hands-on assignments
1. Build a FastAPI CRUD service with Pydantic validation.
2. Add database persistence, authentication, and authorization.
3. Write unit and integration tests with pytest.
4. Add structured logs, error handling, and API documentation.

**Definition of done:** a documented, tested API with predictable error behavior and a reproducible setup.
