# 07 — Machine Learning

**Goal:** Build reproducible classical ML workflows and evaluate models correctly.

## Topics
- NumPy, pandas, visualization, data cleaning
- Train/validation/test splits and data leakage
- Regression, classification, trees, ensembles
- Feature engineering and preprocessing pipelines
- Metrics, cross-validation, calibration, class imbalance
- Error analysis, interpretability, experiment tracking

## Practical assignments
- Build an end-to-end tabular ML pipeline.
- Compare a baseline with at least two stronger models.
- Document metrics, error analysis, and limitations.

**Definition of done:** defend the evaluation methodology and reproduce the results.
