# 04 — Operating Systems

**Goal:** Understand how programs execute and how operating systems manage resources.

## Topics
- Kernel/user mode, system calls, program execution
- Processes, threads, process states, context switching
- CPU scheduling and concurrency
- Race conditions, critical sections, mutexes, semaphores
- Deadlocks and prevention/avoidance
- Memory management, virtual memory, paging
- Filesystems, permissions, pipes, signals

## Practical assignments
- Use process and thread APIs in Python.
- Reproduce and fix a race condition.
- Inspect processes, memory, files, and network sockets using OS tools.

**Definition of done:** explain process/thread behavior, synchronization risks, and memory isolation.
