# 02 — Object-Oriented Programming and Computer Networks

**Goal:** Design maintainable software and understand how applications communicate across networks.

## Part A — Object-Oriented Programming
- Classes, objects, attributes, methods, constructors
- Encapsulation, abstraction, inheritance, polymorphism
- Composition versus inheritance
- Interfaces/protocols, abstract base classes, dependency injection
- SOLID principles, common design patterns, UML/class diagrams, refactoring

### Free video
- [Python OOP — freeCodeCamp full course (2h 37m)](https://www.youtube.com/watch?v=iLRZi0Gu8Go)

### Hands-on assignments
1. Model an inventory or booking domain using classes.
2. Separate domain logic from application entry points.
3. Refactor tightly coupled code using composition and dependency injection.

## Part B — Computer Networks
- OSI and TCP/IP models; encapsulation
- IP addressing, subnet basics, routing, ports
- TCP versus UDP, handshakes, retransmission
- DNS resolution
- HTTP methods, headers, status codes, cookies
- HTTPS, TLS, certificates
- Sockets, proxies, load balancers, CORS
- Latency, throughput, packet loss

### Hands-on assignments
1. Inspect DNS and HTTP requests with `nslookup`, `dig`, `curl`, and browser developer tools.
2. Build a simple client/server socket exercise.
3. Capture and inspect packets with Wireshark.
4. Trace a browser-to-API request and document DNS, TCP, TLS, and HTTP stages.

**Definition of done:** explain OOP design decisions and diagnose common DNS, connection, TLS, and HTTP errors.
