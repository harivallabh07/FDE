# AI-Focused Forward Deployed Engineer (FDE) Roadmap

A six-month, project-driven learning repository for building the software engineering, AI/ML, and deployment skills required for an AI-focused Forward Deployed Engineer role.

## Learning priorities

- Build strong software engineering foundations: Python, problem solving, OOP, DSA, OS, Computer Networks, and DBMS.
- Build and expose reliable backend services and APIs.
- Develop practical ML, deep learning, LLM, and RAG systems.
- Deploy, monitor, debug, and document end-to-end solutions.
- Practice communicating technical trade-offs and solving customer-facing problems.

## How to use this repository

1. Follow [ROADMAP.md](ROADMAP.md) in sequence, adjusting pace when a concept needs more practice.
2. Keep notes, exercises, and code in the relevant topic folder.
3. Record completed work and blockers in [PROGRESS.md](PROGRESS.md).
4. Build projects that integrate multiple topics; document architecture, setup, tests, trade-offs, and a demo.
5. Commit work regularly with descriptive commit messages.

## Suggested weekly rhythm

- Learn concepts and take concise notes.
- Solve implementation exercises without copying solutions.
- Build a small practical assignment.
- Review mistakes and revise earlier topics.
- Publish a weekly progress update and working code.

## Portfolio standard

Every major project should include a problem statement, architecture diagram, setup instructions, environment-variable example, tests, sample inputs/outputs, limitations, and a short demo or screenshots. Never commit secrets, API keys, credentials, or private data.
