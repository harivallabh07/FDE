# AI-Focused Forward Deployed Engineer (FDE) Roadmap

A six-month, project-driven learning repository for building the software engineering, AI/ML, and deployment skills required for an AI-focused Forward Deployed Engineer role.

## Learning priorities
- Build strong engineering foundations through DSA, OOP, Computer Networks, and Operating Systems.
- Build and expose reliable backend services and APIs.
- Develop practical ML, deep learning, LLM, and RAG systems.
- Deploy, monitor, debug, and document end-to-end solutions.
- Practice explaining technical trade-offs and solving customer-facing problems.

## How to use this repository
1. Follow [ROADMAP.md](ROADMAP.md) in sequence, adjusting pace when a concept needs more practice.
2. Use the free video links inside each module; videos are starting points, not substitutes for implementation.
3. Keep notes, exercises, and code in the relevant topic folder.
4. Record completed work and blockers in [PROGRESS.md](PROGRESS.md).
5. Commit work regularly with descriptive commit messages.

## Weekly rhythm
- Learn concepts and take concise notes.
- Reproduce examples by typing the code yourself.
- Complete the module's practical assignment without copying a finished solution.
- Test, debug, and document what you built.
- Publish a weekly progress update.

## Portfolio standard
Every major project should include a problem statement, architecture diagram, setup instructions, environment-variable example, tests, sample inputs/outputs, limitations, and a short demo. Never commit secrets, API keys, credentials, or private data.
