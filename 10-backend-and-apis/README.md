# 10 — Backend Engineering and APIs

**Goal:** Expose application functionality through robust, documented services.

## Topics
- HTTP and REST API design
- FastAPI, routing, request/response validation
- Pydantic schemas and dependency injection
- Database integration and migrations
- Authentication, authorization, input validation
- Error handling, pagination, rate limiting
- Async I/O, background tasks, caching
- pytest, API integration tests, OpenAPI documentation

## Practical assignments
- Build a FastAPI service backed by a database.
- Add validation, authentication, tests, and structured logging.
- Document endpoints and provide example requests.

**Definition of done:** a cleanly documented API with tests and predictable error behavior.
