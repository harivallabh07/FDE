# 05 — Machine Learning

**Goal:** Build reproducible classical ML workflows and evaluate models correctly.

## Topics
- NumPy, pandas, visualization, data cleaning
- Train/validation/test splits and data leakage
- Regression, classification, trees, ensembles
- Feature engineering and preprocessing pipelines
- Metrics, cross-validation, calibration, class imbalance
- Error analysis, interpretability, experiment tracking

## Free video learning
- [Machine Learning with Scikit-Learn — freeCodeCamp full course](https://www.freecodecamp.org/news/machine-learning-with-scikit-learn-full-course/)
- [Scikit-learn MOOC — free, self-paced lessons and executable notebooks](https://inria.github.io/scikit-learn-mooc/)

## Hands-on assignments
1. Build an end-to-end tabular ML pipeline.
2. Compare a baseline with at least two stronger models.
3. Prevent data leakage and use appropriate validation.
4. Document metrics, error analysis, and limitations.

**Definition of done:** defend the evaluation methodology and reproduce the results from a clean environment.
